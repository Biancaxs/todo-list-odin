# Todo List

📝 Interactive task manager built with JavaScript, featuring task creation, editing, filtering, and dynamic project organization.

## Features

- Add and remove tasks
- Edit existing tasks
- Mark tasks as completed
- Organize tasks into projects
- Filter tasks by status
- Set task priorities and due dates
- Dynamic content updates

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Webpack

## What I Learned

- JavaScript modules
- DOM manipulation
- Object-oriented programming
- Local Storage
- Dynamic content rendering
- Managing application state
- Webpack and module bundling
- Organizing complex JavaScript applications

## Project Goal

This project was built as part of The Odin Project curriculum to practice JavaScript modules, object-oriented programming, Webpack, and managing data in a larger front-end application.
